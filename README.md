# Saltmarsh Carbon Ledger, 2021-2026

Reproducibility package for the saltmarsh carbon accounting ledger and estimation scripts.

## Repository Status

**Released.** Version 1.1.0 (2026-02-10) is published. The scripts, metadata and derived products in this repository are the released artefact for this dataset.

## Layout

- `src/` — processing and QA/QC code
- `data/` — station metadata and product index
- `notebooks/` — validation notebooks
- `tests/` — regression checks
